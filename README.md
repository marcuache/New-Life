# New Life · Plan 90 Días (PWA)

Aplicación web progresiva (PWA) para seguimiento de recomposición corporal en 90 días, control de laboratorios (triglicéridos, glucosa y ácido úrico), rutina en casa con 2 mancuernas segura para la espalda baja y menú empatado padre e hija (libre de cacahuate, mariscos, piña y huevo directo).

## Cómo instalar en tu Android y iPad

1. Sube `index.html`, `manifest.json` y `sw.js` a tu repositorio `New-Life` en GitHub.
2. En GitHub, entra a **Settings → Pages** y en **Branch** selecciona `main` (`/root`) y guarda.
3. Abre la URL `https://marcuache.github.io/New-Life/` en tus dispositivos:
   - **En Android (Chrome):** Toca el menú `⋮` → **Instalar aplicación** o **Agregar a la pantalla principal**.
   - **En iPad (Safari):** Toca el botón **Compartir** (cuadro con flecha hacia arriba) → **Agregar a inicio**.
